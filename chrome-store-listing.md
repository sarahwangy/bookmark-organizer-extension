## Description（详细描述，支持简单换行/段落）

```
Bookmark Atlas replaces Chrome's new-tab page with a real dashboard for your bookmarks — not another manager, a way to actually see what you've saved.

FEATURES
• Card or list view of all your real Chrome bookmarks, with YouTube thumbnail previews
• Smart Grouping — one click to find bookmarks scattered across folders that share a domain
• Duplicate detection (URL-normalized, so www./trailing-slash variants are caught)
• Dead-link checking
• Analytics view — pie/bar charts by topic, domain, sub-folder, and month/year added, every chart segment clickable
• A-Z quick-jump index for both card and list views
• Bilingual UI (English / 中文), dark mode, adjustable card sizes
• CSV / JSON export

PRIVACY
This extension only requests the "bookmarks" and "favicon" permissions. It reads and writes your local Chrome bookmarks directly — there is no server, no account, no sync service, and no data ever leaves your browser. See the privacy policy link below for details.

WHO IT'S FOR
If you've got a few hundred (or a few thousand) bookmarks and Chrome's built-in bookmark manager feels useless for actually finding anything, this is for it.

Open source. Feedback and issues welcome on GitHub: https://github.com/sarahwangy/bookmark-organizer-extension
```
